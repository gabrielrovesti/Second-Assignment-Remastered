## Descrizione del Progetto

Questo progetto implementa un convertitore per i primi 1000 numeri interi da arabi a romani e un metodo per stampare i numeri romani in ASCII art.

### Funzionalità

- Conversione da numeri arabi a numeri romani (1-1000)
- Stampa di numeri romani in ASCII art

### Esempi

Convertire il numero 4 in romano:
```
IV
```

Stampare il numero 4 in ASCII art:
```
 ___ __     __
|_ _|\ \   / /
 | |  \ \ / / 
 | |   \ V /  
|___|   \_/   
```
